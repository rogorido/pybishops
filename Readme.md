This repository houses Python code designed to extract data concerning
bishops, with the aim of integrating them into the [Dominicans in the
Early Modern Period database](https://github.com/rogorido/dominicansdb).

The project employs two essential Python libraries:
- The [psycopg](https://www.psycopg.org/) library, which enables
  connection to a [PostgreSQL](https://www.postgresql.org/) database.
- The [BeautifulSoup](https://www.crummy.com/software/BeautifulSoup/)
  library, used for extracting information from HTML documents.

The data obtained have been utilized in various publications, notably:
"Dimensiones globales de una élite de poder: los obispos de la Orden de
Predicadores (1560-1650)". In H. Linares and D. Ochoa (eds.), *En el
paraíso de los altaresélites eclesiásticas, poder, mediación y mecenazgo
en el mundo ibérico moderno. Siglos XVI-XVIII*, Ediciones Doce Calles,
Madrid, 2023, pp. 71-88. See
[here](https://dialnet.unirioja.es/servlet/libro?codigo=971106).

The files were created for several presentations at international
conferences (for instance, [Dominican Culture, Domican
Theology](https://teol.ku.dk/english/Calendar/2021/dominican-culture-dominican-theology-the-order-of-preachers-and-its-spheres-of-action-1215-ca.-1600/),
University of Copenhagen, Juni-July 2021).
